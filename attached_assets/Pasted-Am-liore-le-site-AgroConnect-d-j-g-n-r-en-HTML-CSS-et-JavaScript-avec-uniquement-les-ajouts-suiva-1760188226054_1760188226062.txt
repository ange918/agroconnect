Améliore le site AgroConnect déjà généré en HTML, CSS et JavaScript avec uniquement les ajouts suivants :

1. Importation locale d’images :
   - Remplace les champs d’ajout d’image actuels par un vrai champ :
     <input type="file" multiple accept="image/*">
   - Lors de l’inscription d’un producteur ou restaurant, rends **l’importation d’au moins une image obligatoire**. 
     → Si l’utilisateur tente de soumettre le formulaire sans image, affiche un message d’erreur clair : 
       "Veuillez importer au moins une image avant de continuer."
   - Permets à l’utilisateur de sélectionner les images directement depuis son appareil (via le gestionnaire de fichiers).
   - Affiche un aperçu visuel des images sélectionnées avant validation (miniatures affichées sous le formulaire).
   - Convertis les images sélectionnées en base64 (via FileReader en JavaScript) pour les sauvegarder dans le localStorage.
   - Les images doivent s’afficher automatiquement lorsqu’on recharge la page, grâce à leur sauvegarde locale.

2. Icônes Boxicons :
   - Intègre la bibliothèque Boxicons pour ajouter des icônes modernes et professionnelles.
   - Importation à placer dans le head du site :
     <link href="https://unpkg.com/boxicons@2.1.4/css/boxicons.min.css" rel="stylesheet">
   - Utilise les icônes suivantes (exemples) :
     - bx-home pour le menu Accueil
     - bx-user pour les utilisateurs
     - bx-cart pour le panier
     - bx-leaf pour les produits agricoles
     - bx-message pour WhatsApp ou contact
   - Ajoute ces icônes dans les boutons, menus et titres selon la logique du site.

3. Police d’écriture :
   - Utilise la même police que Spotify, c’est-à-dire **Poppins**.
   - Importation à placer dans le CSS principal :
     @import url('https://fonts.googleapis.com/css2?family=Poppins:wght@400;500;600;700&display=swap');
   - Applique la police sur tout le site :
     body {
       font-family: 'Poppins', sans-serif;
     }

4. Menu burger responsive :
   - Mets en place un menu burger visible sur les écrans mobiles.
   - Le menu doit se transformer automatiquement en icône burger (trois barres horizontales) sur les petits écrans (< 992px).
   - Utilise une icône Boxicons (bx-menu) pour le burger.
   - Au clic sur le burger, le menu latéral ou déroulant s’affiche avec une animation fluide.
   - Ajoute un effet d’ouverture/fermeture doux (transition CSS ou JavaScript simple).
   - Assure-toi que le menu reste accessible, lisible et fluide sur tous les appareils.

5. Navigation via le logo :
   - Sur **toutes les pages du site et tous les comptes (producteurs, restaurants, clients)** :
     → Cliquer sur le logo du site doit **ramener automatiquement à la page d’accueil (index.html)**.
   - Ajoute un petit effet visuel (changement de curseur ou légère animation) au survol du logo pour montrer qu’il est cliquable.

6. Transitions entre pages :
   - Ajoute un effet de **fade-in / fade-out** lorsque l’utilisateur navigue entre les pages du site.
   - Lors du chargement d’une nouvelle page, tout le contenu doit apparaître progressivement (fade-in).
   - Lorsqu’on clique sur un lien pour changer de page, le contenu actuel doit disparaître progressivement (fade-out) avant le redirection.
   - Utilise CSS et JavaScript simples pour cette transition afin que ce soit fluide et performant sur desktop et mobile.

Conserve le design actuel et le style global du site, mais applique ces **sept améliorations** :
- Importation locale d’images avec aperçu et sauvegarde locale,
- Importation d’image obligatoire à l’inscription pour les producteurs et restaurants,
- Icônes Boxicons intégrées partout,
- Police Poppins (comme Spotify),
- Menu burger responsive fonctionnel sur mobile,
- Retour à la page d’accueil en cliquant sur le logo sur toutes les pages,
- Transitions animées fade-in / fade-out entre toutes les pages.
